# AI-Powered Resume Screening Tool

## Overview

The AI-Powered Resume Screening Tool is a smart recruitment application that automates the resume evaluation process using Natural Language Processing (NLP) and Machine Learning. The system extracts skills from uploaded resumes, compares them with job descriptions, and provides candidate-job matching scores to help recruiters identify suitable candidates efficiently.

## Features

* Resume Upload and Analysis
* Automated Skill Extraction
* Job Description Matching
* Candidate Ranking and Scoring
* Internship and Job Recommendations
* Hackathon Recommendations
* Interactive Streamlit Dashboard
* NLP-Based Resume Processing
* Machine Learning-Powered Screening

## How It Works

1. Upload a resume in PDF format.
2. The system extracts text from the resume.
3. NLP techniques identify important skills and keywords.
4. The extracted information is compared with job descriptions.
5. A matching score is generated.
6. Relevant jobs, internships, and hackathons are recommended.
